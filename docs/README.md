# Agent files for the IBEE docs

Machine-readable copies of the IBEE documentation (https://ibee.ai/docs) for AI agents and tools that ingest a docs site in one pass:

- `llms.txt` — index of every docs page, one line each, with a one-line description.
- `llms-full.txt` — the full text of every docs page in one file, each page introduced by a `title:` / `url:` header.

Both are generated by `scripts/build_agent_files.py` in the docs repository from the published site's sitemap and per-page Markdown, and refreshed after each production docs deploy. For a single page, append `.md` to its URL on https://ibee.ai/docs. The docs MCP server is `https://ibee.ai/docs/_mcp/server`.
